COMO SE USA (resumen; detalle en el LEEME de cada carpeta y en el informe)
==============================================================================
 1. XRP: guardar 1_XRP/main.py en la raiz del XRP (XRPCode, Thonny o
    "python3 -m mpremote connect /dev/ttyACM0 fs cp main.py :main.py + reset").
    Cerrar XRPCode/Thonny. XRP con pilas cargadas e interruptor encendido.
 2. Raspberry Pi: copiar la carpeta reto3 e instalar las librerias:
      sudo apt install -y python3-picamera2 python3-serial python3-numpy
      python3 -m pip install --user --break-system-packages "opencv-python-headless==4.10.0.84"
 3. Prueba de comunicacion:   cd reto3 && python3 prueba_serial.py
    (debe decir ping: OK y "Comunicacion y motores OK")
 4. Vuelta:   python3 reto3.py --grabar --stream
    Poner el robot en la salida y presionar el boton del XRP.
    --vel 0.7 lo hace mas lento; Ctrl+C lo detiene.

==============================================================================
PROTOCOLO SERIAL (USB, /dev/ttyACM0, 115200)
==============================================================================
  Pi -> XRP:  "izq,der\n"  potencia de cada rueda entre -1 y 1   (respuesta OK)
              "S" detener · "P" ping (respuesta PONG) · "E:izq,der" esfuerzo crudo
  XRP -> Pi:  "BTN" boton presionado · "INICIO ..." el XRP arranco ·
              "AVISO: ..." motores sin bateria · "ERROR:<linea>"
  Seguridad:  si no llega ningun comando en 0,5 s el XRP detiene los motores.
